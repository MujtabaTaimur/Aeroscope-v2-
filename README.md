# ✈️ AeroScope

A real-time flight tracking application inspired by FlightRadar24, built with React, TypeScript, and Leaflet. Track flights worldwide with live data, interactive maps, and detailed aircraft information.

## 🚀 Features

- **Live Flight Tracking** - Real-time aircraft positions updated every 10 seconds
- **Interactive Map** - Pan, zoom, and click on aircraft for detailed information
- **Advanced Search** - Filter flights by callsign, country, or ICAO24 code
- **Flight Details** - View altitude, speed, heading, vertical rate, and coordinates
- **Live Statistics** - Track total flights with global coverage
- **Responsive Design** - Aviation-themed dark UI with glassmorphism effects
- **Performance Optimized** - Displays up to 500 concurrent flights smoothly

## 🛠️ Tech Stack

- **Frontend Framework**: React 18 with TypeScript
- **Build Tool**: Vite
- **Styling**: Tailwind CSS with custom design system
- **Maps**: Leaflet & React-Leaflet
- **UI Components**: shadcn/ui with Radix UI primitives
- **State Management**: React Hooks
- **Data Fetching**: TanStack Query
- **Routing**: React Router v6
- **Icons**: Lucide React

## 📡 Data Source

AeroScope uses the [OpenSky Network API](https://opensky-network.org/apidoc/) - a free, community-driven aviation data platform that provides real-time flight information without requiring authentication.
